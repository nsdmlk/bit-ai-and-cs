# Contributing

Follow the module outline and define unfamiliar terms before using them. Label assumptions for numerical examples, use identifiable sources for substantive claims, and keep images in the module's assets folder with relative links and provenance. Update the relevant answer key when changing an exercise.

Make focused, meaningful commits under the actual uploader's identity. If uploading another member's work, preserve the author/uploader distinction and authentic supporting evidence privately. Do not create activity-only commits or backdate work.

Ask a different member to check the developed topic and attempt an activity. Record actual findings and corrections or confirmation in project-management/qa-log.md. AI assistance must be disclosed with retained prompts, outputs and verification in the private assessment records; it is not a substitute for a teammate's review.

Do not commit personal logs, student IDs, passwords, tokens or private submission evidence. Run the source validator described in tools/README.md and inspect rendered output before packaging.
