# The five parts of a computer

**Learning objective:** after this section, a beginner should be able to name the five main parts of a computer and explain what each one does.

## 1. Why this matters

Every computer, from a phone to a data-center server, is built from the same five kinds of parts. If you know these five, you have a map. Every later topic — the CPU, memory, performance, networks — fits somewhere on that map.

## 2. Explanation

Here are the five parts, in plain words.

**CPU (processor)** — runs instructions. It does the actual work: adds numbers, compares values, decides what happens next. It is the part that "thinks".

**Memory (RAM)** — fast but temporary storage. It holds the data the CPU is working on right now. When the power goes off, RAM is empty. It is fast because it is close to the CPU.

**Storage (SSD or disk)** — slow but permanent storage. It holds files, programs, photos — everything that must survive a reboot. It is much larger than RAM but much slower.

**Input/Output (I/O)** — keyboard, mouse, screen, speakers, network card. These are how the computer talks to the outside world. Input comes in, output goes out.

**Network** — connects this computer to other computers. It is how data travels between machines: web pages, messages, videos, cloud storage.

The key idea: **a computer is not one thing — it is a few parts working together.** Each part has one job. The CPU computes, memory holds, storage keeps, I/O communicates, the network connects.

## 4. Example

You open a video on your laptop:

- **Storage** — the video file sits on the disk.
- **RAM** — a chunk of the video is loaded into memory so the CPU can work with it.
- **CPU** — decodes the video frames.
- **I/O** — the picture goes to the screen, the sound goes to the speakers.
- **Network** — if the video is online, it first arrives over the network.

One task — and all five parts are involved.
