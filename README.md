## Purpose
Create beginner-friendly learning materials that explain how modern intelligent systems work, from the physical layer to behavior.

## Intended Learners
First-year CS students with basic knowledge. No prior background in hardware, networking, or reinforcement learning is assumed.

## Content Outline
1. **Hardware:** CPU, GPU, CUDA, assembler.
2. **Networks:** PAN, LAN, TCP/IP.
3. **Behaviorist AI:** Reinforcement Learning (intro → Q-learning → on/off-policy → DQN).
4. **The Big Picture:** How hardware and networks enable robots to learn behavior.

## Deliverables
- Study Guide (Markdown)
- PPT Slides
- Video Tutorials
- Live Mini Lecture (RL)
