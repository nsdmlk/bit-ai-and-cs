# Hardware, Networks & Behaviorist AI

**Team:** team · **Institution:** Beijing Institute of Technology (BIT)

Beginner learning material connecting the computer that executes instructions, the network that carries data, and the agent that learns decisions from experience.

## Start reading

Start with the [whole-project outline](CONTENT-OUTLINE.md). It links every module's outcomes, prerequisites, activities, scope and development status.

1. [Hardware: module map](content/Hardware/OUTLINE.md) — CPU, memory, instruction execution, performance and pipelining.
2. [Networks: module map](content/Networks/OUTLINE.md) — layers, IP/routing, transport, DNS, DHCP, HTTP/TLS and SSH.
3. [Behaviorist AI: module map](content/Behaviorist%20AI/OUTLINE.md) — agents, reinforcement learning, Q-learning, policies, DQN and a qualified robotics case.

**Learners:** first-year students. No previous hardware, networking or reinforcement-learning course is assumed. Arithmetic and basic familiarity with computers are enough to start; each module states any additional prerequisites.
