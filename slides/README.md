# Stage 1 Slides and Classroom Report

The editable PowerPoint deck turns the Stage 1 Markdown module into a 13-slide
teaching sequence. It follows the same learning route: hardware, networks,
behaviourist AI, then a cross-module robot example. For the classroom assessment,
the team will show selected slides and evidence in a prerecorded report of no more
than four minutes; the report is not a full lecture through all 13 slides.

- Deck: `Team_Module_Stage1_Learning_Slides.pptx`
- Outline: `slide-outline.md`
- Narrative/report plan: `narrative_plan.md`
- Source content: `../content/`
- Source record: `../references.md`

The deck and report plan must remain aligned with the reviewed Markdown source. The
final classroom MP4 should be packaged offline in `TeamName_Stage1_StatusReport` and
tested from USB before class.
