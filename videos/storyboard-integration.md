# Storyboard 04 — One Robot, Three Modules

## Objective

Learners will connect Hardware, Networks, and Behaviourist AI in one annotated system
without confusing computation, communication, and learning.

| Time | Screen / visual | Narration | Learner action |
|---|---|---|---|
| 0:00–0:20 | Robot and sensor | Introduce the end-to-end question. | Identify the initial observation. |
| 0:20–0:50 | Camera and NIC | Hardware captures, stores, and prepares data. | Name two hardware responsibilities. |
| 0:50–1:20 | Network path | Packets move the observation to another computer. | Label IP and transport roles. |
| 1:20–2:00 | Model computer | CPU/accelerator computes a proposed action. | Distinguish computation from learning. |
| 2:00–2:40 | Agent state and action | The observation becomes state information; the agent selects an action. | Mark state and action. |
| 2:40–3:10 | Reward | The environment returns feedback after the action. | Decide whether reward is immediate or delayed. |
| 3:10–3:40 | Integration activity | Learners annotate six labels on the full path. | Complete the diagram. |
| 3:40–4:00 | Answer and limits | Explain the expected labels and state that this is an illustrative system. | Summarise the chain. |

the scenario as a teaching model unless the team records a real experiment.
