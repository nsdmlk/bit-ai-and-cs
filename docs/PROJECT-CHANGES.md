1. Replaced a generic README and inaccurate all-DONE checklist with working navigation, the correct GitHub profile, explicit statuses and visible remaining requirements.
2. Added a whole-project outline and detailed module maps specifying outcomes, prerequisites, reading order, activities and boundaries.
3. Corrected CPU/memory/clock/CPI/pipeline explanations and defined one consistent teaching machine. Added explained Hardware answers.
4. Corrected network-layer mapping, IP/transport claims, UDP overhead and HTTPS protection. Added an end-to-end trace, DHCP illustration and explained answers.
5. Developed Q-learning as a coherent anchor with exploration, a complete procedure, episode arithmetic and terminal updates. Clarified SARSA/DQN claims and separated the robotics account from demonstrated RL. Added explained answers.
6. Replaced remote Hardware illustrations with original local teaching diagrams, added original Networks/AI diagrams and recorded their provenance.
7. Removed individual logs and student identifiers from the current public snapshot after preserving the original files privately. Earlier Git commits are retained and may still contain the earlier public files.
8. Added a current plan/task list, factual QA record, a recorded architecture review and specific Study Guide/PPT/video adaptation plans.
9. Prepared portable validation and private submission evidence/reporting. The private report identifies the exact source commit and actual package-check results.

The architecture decision was informed by the team's real review meeting on 25 October
