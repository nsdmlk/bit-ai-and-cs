## Required classroom package

The presentation format is one prerecorded MP4 report. Put the final video and any
required supporting media in one clearly named folder:

`TeamName_Stage1_StatusReport`

If multiple files are submitted, submit one ZIP of that folder. Do not submit a link in
place of the actual files. Do not rely on Internet access, account sign-in, cloud
storage, or live GitHub during the classroom report.
